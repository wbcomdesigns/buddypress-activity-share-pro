# Sharing Activities to Social Networks

Every activity in your community's feed has a **Share** button. Opening it shows a menu where you can send the activity to any social network your site administrator has enabled.

## What you will see

Opening the Share button below an activity shows a dropdown with two parts:

- **Reshare** - share the activity inside your community (covered in the next article).
- **Social network buttons** - one icon for each external platform your admin turned on.

Each social button opens that platform's sharing page, with the activity link and title already filled in.

## Networks that can appear

Your admin chooses which of these show and in what order:

| Network | What it does |
|---|---|
| Facebook | Opens the Facebook share dialog with the activity link |
| X (Twitter) | Opens a pre-filled post on X with the activity title and link |
| LinkedIn | Opens the LinkedIn share form with the activity link |
| WhatsApp | Opens WhatsApp with the activity link ready to send |
| Telegram | Opens Telegram with the activity link ready to forward |
| Pinterest | Opens the Pinterest Create Pin page with the activity link |
| Reddit | Opens the Reddit submit-a-link form with the title and link |
| WordPress | Opens the WordPress.com Press This form with the activity link |
| Pocket | Saves the activity link to your Pocket reading list |
| Bluesky | Opens a pre-filled Bluesky compose window with the activity link |
| E-mail | Opens your email client with a subject and body pre-filled |
| Copy Link | Copies the activity link to your clipboard, no new tab |

Not all of these appear on every site. The administrator controls which networks are enabled.

## How to share, step by step

1. Find the activity you want to share in the feed.
2. Click the **Share** button in the activity's action bar.
3. In the menu, find the social network icons below the Reshare button.
4. Click the icon for the network you want.
5. Finish posting on that platform, then return to your community.

For **Copy Link**, no new tab opens. You see a small "Link Copied!" confirmation. Paste the link wherever you need it.

For **E-mail**, your default email client opens with a subject and body already written. Add recipients and send.

## Sharing when you are not logged in

If your administrator has enabled guest sharing, you can share to social networks without logging in. The Reshare option (sharing inside the community) always needs an account.

## Share count

A number next to the Share button shows how many times that activity has been shared, both externally and internally. It updates as shares happen.
