# Activity Share Pro 3.6.0 - Pro implementation plan

Rules for every task:
- Branch `3.6.0` (cut from `2.3.1`, which already carries the security hotfix). Commit locally per task; nothing pushed without owner go-ahead.
- **Pro never calls `BPAS\*` classes** - only Free's `functions.php` API and hooks. CI grep enforces it.
- Done = **Verify** passed in the browser as the named role. Strings use `buddypress-activity-share-pro`; no inline script / style; token-only CSS reusing Free's `bpas-tokens` handle.
- End of each wave: stop for owner review, then move the wave's cards to Ready for Testing with a verification comment.
